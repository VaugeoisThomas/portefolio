# TaskFlow

Projet de gestion de tâches simple, moderne et adapté à un niveau junior.

## Fonctionnalités
- Ajouter une tâche
- Marquer comme terminée
- Supprimer une tâche
- Filtrer les tâches par statut
- Effacer les tâches terminées
- Sauvegarde dans le navigateur via localStorage

## Lancer le projet
Ouvrez simplement le fichier `index.html` dans un navigateur, ou lancez un petit serveur local :

```bash
python -m http.server 8000
```

Puis ouvrez : http://localhost:8000

## Objectif
Ce projet permet de montrer :
- une logique de base propre
- la gestion d’état simple
- une interface fonctionnelle
- une application claire à présenter en portfolio
